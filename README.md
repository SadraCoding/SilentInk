## ✨ Features

- 🔐 AES-256-GCM encryption
- 🔑 PBKDF2-HMAC-SHA512 (800k iterations)
- 🧂 Random salt per encryption
- 🖼 Lossless PNG embedding
- 🎨 Colorized animated CLI
- 🛡 Built-in integrity protection
